# 🏠 Rent Splitter (Equal)

A simple Python script that evenly splits monthly rent among roommates and prints each person’s share with two-decimal currency formatting.

---

## 🧠 Features
- Prompts for total monthly rent
- Prompts for number of roommates
- Calculates an equal split
- Formats output to two decimals (e.g., `$55.00`)

---

## 🧩 Concepts Demonstrated
- User input and type conversion (`float`, `int`)
- Basic arithmetic
- f-string formatting with `:.2f`

---

## 🖥️ Example Output

Welcome to Rent Splitter (Equal)
Total monthly rent: $1500
How many roommates? 3
Each person pays: $500.00
